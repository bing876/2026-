# CL Policy

## Definition

CL represents AI enhanced execution resources, not model purchase credits.

## Usage

Normal single model execution:
- No additional CL or included quota

Enhanced orchestration:
- Multi-model collaboration
- Verification
- Research augmentation
- Advanced planning

May consume CL.

## Future Pricing Factors

- Task complexity
- Number of models
- Token usage
- Execution duration
- Quality requirements
