# Evaluation Criteria Specification

## Quality Dimensions

Each execution result can be evaluated by:

1. Accuracy
2. Completeness
3. User intent alignment
4. Reasoning quality
5. Safety and consistency
6. Cost efficiency

## Model Comparison

The evaluator compares:

- Single model output
- Multi-model output
- Previous successful executions

## Future Evolution

Evaluation data will become training data for Router optimization.
