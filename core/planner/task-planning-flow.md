# Task Planning Flow

## Execution Pipeline

1. Receive user intent
2. Analyze objective
3. Identify task category
4. Generate subtasks
5. Assign required capabilities
6. Send plan to Router
7. Execute through Model Gateway
8. Collect results
9. Evaluate and finalize

## Example

Request:

Develop an e-commerce operation strategy

Planner creates:

- Market research
- User analysis
- Content strategy
- Execution schedule
- Risk review

Each subtask can be routed independently.
