# Router Execution Flow

```
User Request
    |
Task Analysis
    |
Capability Extraction
    |
Complexity Evaluation
    |
Budget Check
    |
Model Selection
    |
Execution Plan
    |
Result Evaluation
    |
Final Response
```

## Rules

1. Primary Model remains the final decision owner.
2. Auxiliary models provide specialized capabilities.
3. Multi-model execution must justify additional cost.
4. Simple tasks should remain single-model execution.

## Future Evolution

Rule engine -> Data optimized router -> Autonomous router agent
