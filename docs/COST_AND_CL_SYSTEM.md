# Cost and CL System v0.1

## CL Definition

CL represents AI enhanced execution resources.

It is not a direct model price unit.

## Execution Modes

Normal Mode:

Primary model only.

Enhanced Mode:

Primary model plus additional specialist models.

Enhanced Mode consumes CL.

## User API Mode

Users may connect their own models.

Basic execution uses user models.

Advanced orchestration may consume CL when platform models are added.

## Cost Control

Every task should estimate:

- Token usage
- Model count
- Expected cost
- Expected quality improvement

The system optimizes value per cost.
