# Model Capability Matrix v0.1

## Principle

XYZ Orchestrator does not bind fixed models to fixed jobs.

Models are evaluated by capability dimensions.

## Capability Dimensions

- Reasoning
- Coding
- Writing
- Long Context
- Research
- Vision
- Planning
- Review
- Data Analysis

## Example Capability Mapping

GPT:
- General intelligence
- Planning
- Complex reasoning

DeepSeek:
- Reasoning
- Coding
- Cost efficiency

Kimi:
- Writing
- Long context processing

Gemini:
- Multimodal analysis
- Research

Claude:
- Review
- Long document reasoning

## Future Evolution

Capability scores will be updated using execution data and evaluation results.
