# XYZ Router Specification v0.1

## Goal

Select the best execution strategy based on task requirements, quality targets and budget.

## Routing Flow

User Request

↓

Task Analysis

↓

Complexity Evaluation

↓

Capability Requirement Extraction

↓

Model Selection

↓

Execution

↓

Evaluation

## Routing Rules

Simple tasks:
Single model execution.

Medium tasks:
Primary model plus selected specialist model.

Complex tasks:
Multi-model collaboration with cost control.

## Primary Model Rule

One task has one final owner model.

Supporting models provide suggestions, analysis or verification.
