# XYZ Routing Policy Examples

## Principle
Routing is based on capability requirements, not fixed model names.

## Example 1: Writing

Primary model:
- User selected model

Optional helpers:
- Writing specialist
- Long context specialist

## Example 2: Coding

Possible routing:
- Reasoning model: architecture
- Coding model: implementation
- Review model: security and quality check

## Example 3: Business Planning

Possible routing:
- Research model
- Strategy model
- Writing model
- Validation model

## Cost Rule
Use the smallest number of models that achieves required quality.
