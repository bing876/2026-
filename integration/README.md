# XYZ Ecosystem Integration

## Goal

Connect XYZ Intelligence Orchestrator with DIMSPACE Workbench, Agent OS and KABU.

## Integration Layers

User -> Workbench -> Agent OS -> XYZ Orchestrator -> Models -> Memory

## Principles

- Orchestrator remains independent.
- Product layers call through SDK.
- Memory and identity use controlled interfaces.
- Project agents are isolated by project context.
