# Identity & Memory Bridge

## Purpose
Connect User Identity, Project Identity, Agent Identity and XYZ Intelligence context.

## Context Flow

User Identity
→ Project Identity
→ Agent Identity
→ Memory Permission
→ Orchestrator Context

## Memory Types

- User Memory
- Project Memory
- Agent Memory
- Execution Memory

## Rules

1. Identity controls access scope.
2. Memory is loaded only within authorized context.
3. Execution traces can update learning memory after evaluation.
